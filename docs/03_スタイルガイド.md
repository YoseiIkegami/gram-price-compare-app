# スタイルガイド

## 1. 概要

本ドキュメントは「どち得？ グラム単価比較アプリ」のデザインシステムとスタイルガイドを定義します。

## 2. デザイン原則

### 2.1 Apple Human Interface Guidelines (HIG) 準拠

本アプリはApple HIGの原則に基づいて設計されています。

- **8ptグリッド**: すべての余白、サイズ、パディングは8の倍数
- **44x44ptルール**: タップ領域は最小44x44pt
- **セマンティックカラー**: 役割で色を定義
- **スプリングアニメーション**: 自然な動きを実現

詳細は `.cursorrules` を参照してください。

## 3. カラーパレット

### 3.1 セマンティックカラー

| カラー名 | 用途 | CSS変数 |
|---------|------|---------|
| `primary` | 主要アクション、強調表示 | `var(--color-primary)` |
| `background` | 背景色 | `var(--color-background)` |
| `surface` | カード、パネルの背景 | `var(--color-surface)` |
| `foreground` | 主要テキスト | `var(--color-foreground)` |
| `muted` | 副次的なテキスト | `var(--color-muted)` |
| `border` | 境界線 | `var(--color-border)` |
| `success` | 成功メッセージ | `var(--color-success)` |
| `warning` | 警告メッセージ | `var(--color-warning)` |
| `error` | エラーメッセージ、削除ボタン | `var(--color-error)` |

### 3.2 カラー値（将来の拡張）

現在はCSS変数で定義されていますが、将来的に以下のような値を設定予定：

```css
:root {
  --color-primary: #007AFF;      /* iOS Blue */
  --color-background: #FFFFFF;
  --color-surface: #F2F2F7;
  --color-foreground: #000000;
  --color-muted: #8E8E93;
  --color-border: #C6C6C8;
  --color-success: #34C759;
  --color-warning: #FF9500;
  --color-error: #FF3B30;
}
```

## 4. タイポグラフィ

### 4.1 フォントサイズ

| 用途 | モバイル | PC | Tailwindクラス |
|------|---------|-----|---------------|
| グラム単価 | 36px | 48px | `text-4xl md:text-5xl` |
| 最安商品サマリー | 30px | 48px | `text-3xl md:text-5xl` |
| 見出し（h1） | 24px | 24px | `text-2xl` |
| 見出し（h2） | 18px | 18px | `text-lg` |
| 本文 | 16px | 18px | `text-base md:text-lg` |
| キャプション | 12px | 12px | `text-xs` |

### 4.2 フォントウェイト

- **Bold**: `font-bold` - グラム単価、見出し
- **Semibold**: `font-semibold` - ボタン、ラベル
- **Medium**: `font-medium` - タブバー
- **Regular**: デフォルト - 本文

### 4.3 行間（Line Height）

- **Body**: 約1.3〜1.5倍（`leading-relaxed`）
- **Title**: 約1.2〜1.3倍

## 5. スペーシング

### 5.1 8ptグリッド

すべての余白、サイズ、パディングは8の倍数で設計：

- **4pt**: 微調整用
- **8pt**: 最小単位
- **16pt**: 標準の余白
- **24pt**: カードのパディング
- **32pt**: セクション間の余白
- **48pt**: 大きなセクション間の余白

### 5.2 パディング・マージン

| 用途 | 値 | Tailwindクラス |
|------|-----|---------------|
| カードパディング | 24px | `p-6` |
| 画面端からの余白（モバイル） | 16px | `px-4` |
| 画面端からの余白（PC） | 24px | `px-6` |
| セクション間（モバイル） | 16px | `space-y-4` |
| セクション間（PC） | 24px | `space-y-6` |

## 6. 角丸（Border Radius）

| 用途 | 値 | Tailwindクラス |
|------|-----|---------------|
| カード、コンテナ | 20px | `rounded-2xl` |
| ボタン | 12px | `rounded-lg` |
| バッジ、小さな要素 | 8px | `rounded` |

## 7. シャドウ

| 用途 | Tailwindクラス |
|------|---------------|
| カード | `shadow-lg` |
| タブバー | `shadow-md` |

## 8. ボタン

### 8.1 ボタンスタイル

#### プライマリボタン
```tsx
className="bg-primary text-background font-semibold rounded-lg py-3 px-4"
```

#### セカンダリボタン
```tsx
className="bg-surface border border-border text-foreground font-semibold rounded-lg py-2.5 px-4"
```

#### エラーボタン（削除）
```tsx
className="bg-error/10 border border-error text-error font-semibold rounded-lg py-2.5 px-4"
```

### 8.2 ボタンサイズ

- **最小タップ領域**: 44x44pt（`min-h-[56px]`）
- **パディング**: `py-2.5 px-4` または `py-3 px-4`

### 8.3 ボタンの状態

- **通常**: 不透明度1.0
- **ホバー**: `hover:opacity-80`
- **アクティブ**: `active:opacity-70`
- **無効**: `disabled:opacity-50`

## 9. 入力フィールド

### 9.1 スタイル

```tsx
className="text-base md:text-lg font-medium text-foreground py-2.5 pl-3 pr-2 outline-none bg-transparent min-h-[56px]"
```

### 9.2 フォントサイズ

- **最小**: 16px（`text-base`）- iOS Safariの自動ズームを防ぐため
- **PC**: 18px（`md:text-lg`）

### 9.3 プレースホルダー

- **色**: `text-muted`（グレー）
- **スタイル**: 通常のテキストより薄く表示

## 10. カード

### 10.1 スタイル

```tsx
className="bg-surface rounded-2xl p-6 border border-border"
```

### 10.2 最安商品カード

```tsx
className="bg-surface rounded-2xl p-6 md:p-8 border-2 border-primary shadow-lg"
```

## 11. アイコン

### 11.1 サイズ

- **小**: `w-4 h-4`（16px）- ボタン内
- **中**: `w-7 h-7`（28px）- タブバー
- **大**: `text-3xl md:text-4xl`（30-32px）- 装飾用

### 11.2 SVGアイコン

- **ストローク幅**: `strokeWidth={2}`
- **角丸**: `strokeLinecap="round" strokeLinejoin="round"`

## 12. アニメーション

### 12.1 トランジション

- **時間**: 100ms〜150ms
- **イージング**: `ease-in-out`

```tsx
className="transition-opacity"
```

### 12.2 スプリングアニメーション（将来の拡張）

将来、より高度なアニメーションを実装する場合は、以下のパラメータを使用：

- **damping**: 15
- **stiffness**: 150

## 13. レスポンシブデザイン

### 13.1 ブレークポイント

- **モバイル**: デフォルト（〜767px）
- **タブレット/PC**: `md:` プレフィックス（768px〜）

### 13.2 レスポンシブクラス

```tsx
// フォントサイズ
className="text-base md:text-lg"

// パディング
className="px-4 md:px-6"

// スペーシング
className="space-y-4 md:space-y-6"
```

## 14. アクセシビリティ

### 14.1 コントラスト比

- **本文**: 4.5:1以上（WCAG 2.1 AA準拠）
- **大きなテキスト**: 3:1以上

### 14.2 フォーカス表示

- **アウトライン**: `outline-none`（カスタムスタイルで上書き可能）

## 15. ダークモード

現在は対応していませんが、将来の拡張として検討。
