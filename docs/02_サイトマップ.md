# サイトマップ

## 1. 概要

本ドキュメントは「どち得？ グラム単価比較アプリ」のサイト構造を定義します。

## 2. サイト構造

```
どち得？ グラム単価比較アプリ
│
├─ 計算画面 (/)
│  ├─ 商品カード1
│  ├─ 商品カード2
│  ├─ 商品カード3（オプション）
│  ├─ 商品カード4（オプション）
│  └─ 最安商品サマリー
│
└─ About画面 (/about)
   ├─ アプリ説明
   ├─ 使い方
   ├─ 機能一覧
   └─ 寄付セクション
```

## 3. ナビゲーション

### 3.1 タブバー

**位置**: 画面下部（固定）

**タブ**:
- **計算**: 計算画面に遷移
- **About**: About画面に遷移

**動作**:
- タブをタップすると、該当画面に切り替わる
- アクティブなタブは青色で強調表示
- 画面遷移は即座に反映（アニメーションなし）

### 3.2 内部リンク

現在、内部リンクはありません。すべてタブバーによる画面切り替えで実現しています。

## 4. ルーティング

### 4.1 現在の実装

**方式**: クライアントサイドルーティング（React State）

**ルート定義**:
- `/` → 計算画面（`Calculator`コンポーネント）
- `/about` → About画面（`About`コンポーネント）

**実装**:
```typescript
const [activeTab, setActiveTab] = useState<'calculator' | 'about'>('calculator');
```

### 4.2 将来の拡張

履歴機能追加時は、以下のルートを追加予定：
- `/history` → 履歴一覧画面

その際は、React Routerなどのルーティングライブラリの導入を検討。

## 5. URL構造

### 5.1 現在

- **ルートURL**: `/`
- **About**: `/about`（タブ切り替えのみ、URLは変更されない）

### 5.2 将来の拡張

履歴機能追加時：
- `/history` → 履歴一覧
- `/history/:id` → 履歴詳細（再計算）

## 6. ページ遷移フロー

```
起動
  ↓
計算画面（初期状態）
  ↓
[タブバー: About] → About画面
  ↓
[タブバー: 計算] → 計算画面
```

## 7. 深いリンク（Deep Link）

現在は対応していませんが、将来の拡張として以下を検討：

- 共有機能: 計算結果をURLパラメータで共有
- 履歴への直接リンク: `/history/:id` で履歴を直接開く

## 8. 404エラーページ

現在は実装されていません。SPA（Single Page Application）のため、存在しないパスにアクセスしてもルート画面が表示されます。

将来の拡張として、404エラーページの実装を検討。
