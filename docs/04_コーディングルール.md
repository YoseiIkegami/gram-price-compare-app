# コーディングルール

## 1. 概要

本ドキュメントは「どち得？ グラム単価比較アプリ」のコーディング規約を定義します。

## 2. 言語・フレームワーク

- **言語**: TypeScript
- **フレームワーク**: React 18
- **ビルドツール**: Vite
- **スタイリング**: Tailwind CSS

## 3. ファイル命名規則

### 3.1 コンポーネント

- **ファイル名**: PascalCase（例: `ProductCard.tsx`）
- **コンポーネント名**: ファイル名と一致

```typescript
// ProductCard.tsx
export default function ProductCard() {
  // ...
}
```

### 3.2 ユーティリティ・ライブラリ

- **ファイル名**: camelCase（例: `calculator.ts`, `utils.ts`）
- **関数名**: camelCase

```typescript
// calculator.ts
export function calculatePricePerGram(price: number, weight: number): number {
  // ...
}
```

### 3.3 定数

- **ファイル名**: camelCase（例: `constants.ts`）
- **定数名**: UPPER_SNAKE_CASE

```typescript
// constants.ts
export const MAX_PRODUCTS = 4;
export const PRICE_COMPARISON_TOLERANCE = 0.01;
```

## 5. TypeScript

### 5.1 型定義

- **インターフェース**: PascalCase
- **型エイリアス**: PascalCase
- **型パラメータ**: 単一文字の大文字（例: `T`, `K`, `V`）

```typescript
interface Product {
  label: string;
  index: number;
  price: number;
  weight: number;
  pricePerGram: number;
}

type Tab = 'calculator' | 'about';
```

### 5.2 型注釈

- **関数の引数・戻り値**: 必ず型を明示
- **変数**: 型推論可能な場合は省略可

```typescript
// 良い例
function calculatePricePerGram(price: number, weight: number): number {
  return price / weight;
}

// 良い例（型推論可能）
const products = useState<Product[]>([]);

// 悪い例（型が不明確）
function calculate(price, weight) {
  return price / weight;
}
```

### 5.3 非nullアサーション

- 可能な限り避ける
- 使用する場合は、コメントで理由を明記

```typescript
// 避ける
const element = document.getElementById('root')!;

// 推奨
const element = document.getElementById('root');
if (!element) {
  throw new Error('Root element not found');
}
```

- **デフォルトエクスポート**: ページコンポーネント、主要コンポーネント
- **名前付きエクスポート**: 再利用可能なコンポーネント、ユーティリティ

```typescript

export default function Calculator() {
  // ...
}

// 名前付きエクスポート

  // ...

```

### 6.2 Hooks

- **カスタムフック**: `use` プレフィックス
- **依存配列**: 必ず指定

```typescript
// カスタムフック
function useProductComparison(products: Product[]) {
  // ...
}

// 依存配列を必ず指定
useEffect(() => {
  // ...
```

- **ローカル状態**: `useState`

- **コールバック**: `useCallback`

```typescript
const comparison = useMemo(
```

## 7. スタイリング

### 7.1 Tailwind CSS

- **ユーティリティクラス**: 優先的に使用
- **カスタムクラス**: 必要な場合のみ
- **インラインスタイル**: 避ける（動的な値の場合のみ）

```typescript
// 良い例
<div className="flex items-center justify-between bg-surface rounded-lg p-4">

// 悪い例
<div style={{ display: 'flex', alignItems: 'center', ... }}>
```

### 7.2 クラス名の結合

- **`clsx` または `tailwind-merge`**: 条件付きクラスに使用

```typescript
import { cn } from '../lib/utils';

<div className={cn(
  'text-4xl font-bold',
  isCheapest ? 'text-primary' : 'text-foreground'
)}>
```

### 7.3 レスポンシブデザイン

- **モバイルファースト**: デフォルトはモバイル、`md:` でPC対応

```typescript
<div className="text-base md:text-lg px-4 md:px-6">
```

## 9. エラーハンドリング

### 9.1 エラー処理

- **早期リターン**: エラーケースを先に処理
- **エラーメッセージ**: ユーザーに分かりやすく

```typescript
function calculatePricePerGram(price: number, weight: number): number {
  if (price <= 0 || weight <= 0) return 0;
  return Math.round((price / weight) * 100) / 100;
}
```

## 10. パフォーマンス

### 10.1 最適化

- **`useMemo`**: 重い計算をメモ化
- **`useCallback`**: コールバック関数をメモ化
- **`React.memo`**: 必要に応じてコンポーネントをメモ化

```typescript
const comparison = useMemo(
  () => compareProducts(products, PRICE_COMPARISON_TOLERANCE),
  [products]
);

const handlePriceChange = useCallback((index: number, price: number) => {
  // ...
}, []);
```

### 10.2 レンダリング最適化

- **不要な再レンダリング**: 避ける
- **キーの使用**: リストには一意のキーを指定

```typescript
{products.map((product) => (
  <ProductCard key={product.index} {...product} />
))}
```
