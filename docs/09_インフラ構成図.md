# インフラ構成図

## 1. 概要

本ドキュメントは「どち得？ グラム単価比較アプリ」のインフラ構成を定義します。

## 2. 現在の構成

### 2.1 アーキテクチャ

```
┌─────────────────────────────────────────┐
│          ユーザーのブラウザ              │
│  (Chrome, Safari, Firefox, Edge等)      │
└─────────────────────────────────────────┘
                    │
                    │ HTTPS
                    │
┌─────────────────────────────────────────┐
│          Vercel (CDN)                   │
│  - 静的ファイル配信                      │
│  - 自動デプロイ                         │
│  - HTTPS証明書管理                      │
└─────────────────────────────────────────┘
                    │
                    │
┌─────────────────────────────────────────┐
│        GitHub (ソースコード)            │
│  - コードリポジトリ                     │
│  - バージョン管理                       │
└─────────────────────────────────────────┘
```

### 2.2 技術スタック

- **フロントエンド**: React 18 + TypeScript + Vite
- **スタイリング**: Tailwind CSS
- **ホスティング**: Vercel
- **ビルド**: Vite（静的サイト生成）
- **データ保存**: ローカルストレージ（ブラウザ内）

### 2.3 デプロイフロー

```
開発者
  ↓
GitHubにプッシュ
  ↓
Vercelが自動検知
  ↓
自動ビルド（pnpm build）
  ↓
静的ファイルをCDNに配信
  ↓
ユーザーがアクセス
```

---

## 3. 詳細構成

### 3.1 フロントエンド

**技術**:
- React 18
- TypeScript
- Vite
- Tailwind CSS

**ビルド**:
- **コマンド**: `pnpm build`
- **出力**: `dist/` ディレクトリ
- **形式**: 静的HTML、CSS、JavaScript

**デプロイ**:
- **プラットフォーム**: Vercel
- **ビルドコマンド**: `pnpm build`
- **出力ディレクトリ**: `dist`
- **Node.jsバージョン**: 18.x以上

---

### 3.2 ホスティング（Vercel）

**機能**:
- **CDN**: グローバルCDNによる高速配信
- **HTTPS**: 自動HTTPS証明書
- **自動デプロイ**: GitHub連携による自動デプロイ
- **プレビュー**: プルリクエストごとのプレビュー環境

**設定ファイル**: `vercel.json`

```json
{
  "buildCommand": "pnpm build",
  "outputDirectory": "dist",
  "devCommand": "pnpm dev",
  "installCommand": "pnpm install",
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}
```

---

### 3.3 データ保存

**現在**: ローカルストレージ（ブラウザ内）

- **キー**: `gram-price-compare-history`
- **形式**: JSON
- **容量制限**: 約5-10MB（ブラウザ依存）

**将来の拡張**: バックエンドAPI + データベース

---

## 5. セキュリティ

### 5.1 HTTPS

- **必須**: すべての通信はHTTPS
- **証明書**: Vercelが自動管理

### 5.2 CORS（将来の拡張）

- **許可オリジン**: アプリのドメインのみ
- **メソッド**: GET, POST, DELETE
- **ヘッダー**: Authorization, Content-Type

### 5.3 認証（将来の拡張）

- **方式**: JWT（JSON Web Token）
- **保存**: HttpOnly Cookie または localStorage

---

## 6. パフォーマンス

### 6.1 CDN

- **配信**: VercelのグローバルCDN
- **キャッシュ**: 静的ファイルは自動キャッシュ

### 6.2 ビルド最適化

- **コード分割**: Viteが自動的に実装
- **圧縮**: Gzip/Brotli圧縮（Vercelが自動実装）
- **画像最適化**: 将来の拡張で検討

### 6.3 キャッシュ戦略

- **静的ファイル**: 長期キャッシュ（1年）
- **HTML**: 短期キャッシュ（1時間）

---

## 11. デプロイメント

### 11.1 現在のデプロイフロー

1. **開発**: ローカルで開発
2. **コミット**: GitHubにプッシュ
3. **自動デプロイ**: Vercelが自動検知してビルド・デプロイ
4. **確認**: デプロイ完了後、自動的にURLが生成

### 11.2 環境

- **本番環境**: `main` ブランチにプッシュ
- **プレビュー環境**: プルリクエストごとに自動生成
