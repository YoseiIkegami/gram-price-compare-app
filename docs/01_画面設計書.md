# 画面設計書

## 1. 概要

本ドキュメントは「どち得？ グラム単価比較アプリ」の画面設計を定義します。

## 2. 画面一覧

### 2.1 計算画面（Calculator）

**パス**: `/`（ルート）

**説明**: 商品の価格と内容量を入力し、グラム単価を比較するメイン画面

**主要コンポーネント**:
- ヘッダー（クリアボタン、追加ボタン）
- 商品カード（最大4つ）
- 最安商品サマリー

**レイアウト**:
```
┌─────────────────────────┐
│ [クリア]      [追加]     │ ← ヘッダー
├─────────────────────────┤
│                         │
│  ┌─────────────────┐   │
│  │ 商品1           │   │ ← 商品カード1
│  │ 価格: [____]円  │   │
│  │ 内容量: [____]g │   │
│  │ 単価: 0.00円/g  │   │
│  └─────────────────┘   │
│                         │
│  ┌─────────────────┐   │
│  │ 商品2           │   │ ← 商品カード2
│  │ ...             │   │
│  └─────────────────┘   │
│                         │
│  ┌─────────────────┐   │
│  │ 👑 最安商品     │   │ ← 最安商品サマリー
│  │ 商品1 0.50円/g  │   │
│  └─────────────────┘   │
│                         │
└─────────────────────────┘
│ [計算]  [About]        │ ← タブバー
└─────────────────────────┘
```

**要素詳細**:

#### ヘッダー
- **クリアボタン**: すべての入力値をリセット
- **追加ボタン**: 商品を追加（最大4つまで）

#### 商品カード
- **商品名**: 編集可能（タップで編集モード）
- **価格入力欄**: 数値入力（円）
- **内容量入力欄**: 数値入力（g）
- **グラム単価表示**: 自動計算（円/g）
- **削除ボタン**: 商品が3つ以上の場合に表示

#### 最安商品サマリー
- **表示条件**: 有効な商品が2つ以上、かつ最安商品が存在する場合
- **内容**: 最安商品名、グラム単価
- **スタイル**: 青色の強調表示、👑アイコン

## 3. レスポンシブデザイン

### 3.1 ブレークポイント

- **モバイル**: デフォルト（〜767px）
- **タブレット/PC**: `md:` プレフィックス（768px〜）

### 3.2 フォントサイズ

| 要素 | モバイル | PC |
|------|---------|-----|
| グラム単価 | `text-4xl` (36px) | `text-5xl` (48px) |
| 入力フィールド | `text-base` (16px) | `text-lg` (18px) |
| 最安商品サマリー | `text-3xl` (30px) | `text-5xl` (48px) |

### 3.3 パディング・マージン

- **カードパディング**: `p-6` (24px)
- **セクション間**: `space-y-4 md:space-y-6`
- **画面端からの余白**: `px-4 md:px-6`

## 4. インタラクション

### 4.1 入力フィールド

- **フォーカス時**: 自動ズームなし（`viewport`設定）
- **Enterキー**: 次の入力欄にフォーカス移動
- **入力モード**: `inputMode="decimal"`（数値キーパッド表示）

### 4.2 ボタン

- **タップ領域**: 最小44x44pt（Apple HIG準拠）
- **フィードバック**: 押下時に不透明度が下がる（`opacity: 0.7`）

### 4.3 タブバー

- **アクティブタブ**: 青色（`text-primary`）、不透明度1.0
- **非アクティブタブ**: グレー（`text-muted`）、不透明度0.6

## 5. 状態管理

### 5.1 商品データ

```typescript
interface Product {
  label: string;        // 商品名
  index: number;        // 一意の識別子
  price: number;        // 価格（円）
  weight: number;       // 内容量（g）
  pricePerGram: number; // グラム単価（円/g）
}
```

### 5.2 UI状態

- `activeTab`: 現在のタブ（'calculator' | 'about'）
- `editingLabel`: 編集中の商品名のindex（null | number）
- `isAddingProduct`: 商品追加中のフラグ

## 6. エラーハンドリング

現在はエラーハンドリングは実装されていませんが、将来の拡張として以下を検討：

- 入力値のバリデーション（負の値、非数値など）
- エラーメッセージの表示
- 入力制限（最大値など）

## 7. アクセシビリティ

- **セマンティックHTML**: 適切なHTMLタグを使用
- **キーボード操作**: すべての機能がキーボードで操作可能
- **フォーカス管理**: 論理的な順序でフォーカス移動
- **コントラスト比**: WCAG 2.1 AA準拠（4.5:1以上）
