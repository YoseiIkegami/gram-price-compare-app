# テーブル定義書

## 1. 概要

本ドキュメントは「どち得？ グラム単価比較アプリ」のデータベーステーブル定義を記載します。

**注意**: 現在、本アプリはフロントエンドのみのアプリケーションであり、データベースは使用していません。本ドキュメントは、将来の拡張を想定した定義を記載しています。

### 2.1 現在の実装

- **データ保存**: なし（メモリ内のみ）
- **将来の拡張**: ローカルストレージ（localStorage）またはバックエンドデータベース

### 2.2 将来の拡張予定

- **データベース**: PostgreSQL
- **ORM**: Prisma または TypeORM（検討中）

| id | UUID | PRIMARY KEY | 履歴ID |

## 5. データ型の詳細

### 5.1 UUID

- **用途**: 主キー、外部キー
- **形式**: `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`
- **生成**: データベース側で自動生成（`gen_random_uuid()`）

### 5.2 DECIMAL

- **用途**: 金額、重量、グラム単価
- **精度**: 
  - 価格・重量: `DECIMAL(10, 2)`（整数部8桁、小数部2桁）
  - グラム単価: `DECIMAL(10, 4)`（整数部6桁、小数部4桁）

### 5.3 TIMESTAMP

- **用途**: 作成日時、更新日時
- **タイムゾーン**: UTC
- **自動更新**: `updated_at` は更新時に自動更新

## 6. 制約

### 6.1 主キー制約

- すべてのテーブルに `id` を主キーとして設定

### 6.2 外部キー制約

- `history.user_id` → `users.id` (ON DELETE CASCADE)
- `history_products.history_id` → `history.id` (ON DELETE CASCADE)

### 6.3 チェック制約

**history_products**:
- `price >= 0`: 価格は0以上
- `weight > 0`: 内容量は0より大きい
- `price_per_gram >= 0`: グラム単価は0以上
- `product_index >= 1`: 商品の順序は1以上

---

### 7.2 外部キーインデックス

### 7.3 検索用インデックス

## 9. マイグレーション（将来の拡張）

### 9.1 初期スキーマ

```sql
-- users テーブル
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) UNIQUE NOT NULL,
  name VARCHAR(100),
  created_at TIMESTAMP NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMP NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_users_email ON users(email);

-- history テーブル
CREATE TABLE history (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  created_at TIMESTAMP NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMP NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_history_user_id ON history(user_id);
CREATE INDEX idx_history_created_at ON history(created_at);

-- history_products テーブル
CREATE TABLE history_products (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  history_id UUID NOT NULL REFERENCES history(id) ON DELETE CASCADE,
  label VARCHAR(100) NOT NULL,
  price DECIMAL(10, 2) NOT NULL CHECK (price >= 0),
  weight DECIMAL(10, 2) NOT NULL CHECK (weight > 0),
  price_per_gram DECIMAL(10, 4) NOT NULL CHECK (price_per_gram >= 0),
  product_index INTEGER NOT NULL CHECK (product_index >= 1),
  is_cheapest BOOLEAN NOT NULL DEFAULT FALSE,
  created_at TIMESTAMP NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_history_products_history_id ON history_products(history_id);
```

### 9.2 更新トリガー

```sql
-- updated_at を自動更新するトリガー
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = NOW();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER update_users_updated_at
  BEFORE UPDATE ON users
  FOR EACH ROW
  EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_history_updated_at
  BEFORE UPDATE ON history
  FOR EACH ROW
  EXECUTE FUNCTION update_updated_at_column();
```
