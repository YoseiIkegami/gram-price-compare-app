# ER図

## 1. 概要

本ドキュメントは「どち得？ グラム単価比較アプリ」のデータベースER図を記載します。

**注意**: 現在、本アプリはフロントエンドのみのアプリケーションであり、データベースは使用していません。本ドキュメントは、将来の拡張を想定したER図を記載しています。

## 2. ER図

```
┌─────────────────────────────────┐
│           users                │
├─────────────────────────────────┤
│ id (PK)              UUID       │
│ email                VARCHAR    │
│ name                 VARCHAR    │
│ created_at           TIMESTAMP  │
│ updated_at           TIMESTAMP  │
└─────────────────────────────────┘
            │
            │ 1
            │
            │ N
            │
┌─────────────────────────────────┐
│          history                 │
├─────────────────────────────────┤
│ id (PK)              UUID       │
│ user_id (FK)          UUID       │
│ created_at           TIMESTAMP  │
│ updated_at           TIMESTAMP  │
└─────────────────────────────────┘
            │
            │ 1
            │
            │ N
            │
┌─────────────────────────────────┐
│      history_products            │
├─────────────────────────────────┤
│ id (PK)              UUID       │
│ history_id (FK)       UUID       │
│ label                 VARCHAR    │
│ price                 DECIMAL    │
│ weight                DECIMAL    │
│ price_per_gram        DECIMAL    │
│ product_index         INTEGER    │
│ is_cheapest           BOOLEAN    │
│ created_at            TIMESTAMP  │
└─────────────────────────────────┘
```

## 3. エンティティ詳細

### 3.1 users（ユーザー）

**説明**: アプリを使用するユーザー情報

**主キー**: `id`

**属性**:
- `id`: ユーザーID（UUID）
- `email`: メールアドレス（ユニーク）
- `name`: ユーザー名
- `created_at`: 作成日時
- `updated_at`: 更新日時

**関係**:
- `history` と 1:N の関係（1人のユーザーは複数の履歴を持つ）

---

### 3.2 history（履歴）

**説明**: ユーザーの計算履歴

**主キー**: `id`

**属性**:
- `id`: 履歴ID（UUID）
- `user_id`: ユーザーID（外部キー）
- `created_at`: 作成日時
- `updated_at`: 更新日時

**関係**:
- `users` と N:1 の関係（複数の履歴は1人のユーザーに属する）
- `history_products` と 1:N の関係（1つの履歴は複数の商品を持つ）

---

### 3.3 history_products（履歴商品）

**説明**: 履歴に紐づく商品情報

**主キー**: `id`

**属性**:
- `id`: 履歴商品ID（UUID）
- `history_id`: 履歴ID（外部キー）
- `label`: 商品名
- `price`: 価格（円）
- `weight`: 内容量（g）
- `price_per_gram`: グラム単価（円/g）
- `product_index`: 商品の順序（1, 2, 3, 4...）
- `is_cheapest`: 最安商品フラグ
- `created_at`: 作成日時

**関係**:
- `history` と N:1 の関係（複数の商品は1つの履歴に属する）

---

## 4. 関係の詳細

### 4.1 users ↔ history

**関係**: 1:N（一対多）

**説明**: 1人のユーザーは複数の履歴を持つことができます。

**外部キー**: `history.user_id` → `users.id`

**カーディナリティ**:
- ユーザー側: 1（1人のユーザー）
- 履歴側: N（複数の履歴）

**削除時の動作**: CASCADE（ユーザーを削除すると、そのユーザーの履歴も削除される）

---

### 4.2 history ↔ history_products

**関係**: 1:N（一対多）

**説明**: 1つの履歴は複数の商品を持つことができます。

**外部キー**: `history_products.history_id` → `history.id`

**カーディナリティ**:
- 履歴側: 1（1つの履歴）
- 商品側: N（複数の商品、最大4つ）

**削除時の動作**: CASCADE（履歴を削除すると、その履歴の商品も削除される）

---

## 5. 制約

### 5.1 主キー制約

- `users.id`: PRIMARY KEY
- `history.id`: PRIMARY KEY
- `history_products.id`: PRIMARY KEY

### 5.2 外部キー制約

- `history.user_id` → `users.id` (ON DELETE CASCADE)
- `history_products.history_id` → `history.id` (ON DELETE CASCADE)

### 5.3 ユニーク制約

- `users.email`: UNIQUE

### 5.4 チェック制約

**history_products**:
- `price >= 0`: 価格は0以上
- `weight > 0`: 内容量は0より大きい
- `price_per_gram >= 0`: グラム単価は0以上
- `product_index >= 1`: 商品の順序は1以上

---

## 6. インデックス

### 6.1 主キーインデックス

- `users.id`
- `history.id`
- `history_products.id`

### 6.2 外部キーインデックス

- `history.user_id`
- `history_products.history_id`

### 6.3 検索用インデックス

- `users.email`: メールアドレスでの検索
- `history.created_at`: 日時でのソート・検索

---

## 7. 正規化

### 7.1 第1正規形（1NF）

✅ すべてのテーブルは第1正規形を満たしています。

- 各カラムは原子値（分割不可能な値）
- 各行は一意

### 7.2 第2正規形（2NF）

✅ すべてのテーブルは第2正規形を満たしています。

- 第1正規形を満たしている
- 部分関数従属がない

### 7.3 第3正規形（3NF）

✅ すべてのテーブルは第3正規形を満たしています。

- 第2正規形を満たしている
- 推移的関数従属がない

---

## 8. データ整合性

### 8.1 参照整合性

- 外部キー制約により、存在しないユーザーや履歴を参照できない
- CASCADE削除により、親レコードを削除すると子レコードも自動削除

### 8.2 ドメイン整合性

- チェック制約により、不正な値の挿入を防止
- データ型により、型の整合性を保証

## 10. ローカルストレージ（現在の実装予定）

### 10.1 データ構造

現在はデータベースを使用していないため、ローカルストレージに以下の構造で保存：

```typescript
interface HistoryItem {
  id: string;
  timestamp: number;
  products: Product[];
  cheapestIndex: number | null;
}
```

### 10.2 ER図との対応

- **users**: なし（ローカルストレージではユーザー管理なし）
- **history**: `HistoryItem` に相当
- **history_products**: `HistoryItem.products` に相当
